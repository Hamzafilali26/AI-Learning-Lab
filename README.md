# AI Learning Lab

A structured learning repository for becoming proficient in:

- Python for AI
- Mathematics for Machine Learning
- Classical Machine Learning
- Deep Learning
- NLP and LLMs
- Recommendation Systems
- Computer Vision
- Time Series
- MLOps and LLMOps
- Low-Code AI tools

## Learning Method

Each topic follows this structure:

1. Definition
2. Why the concept matters
3. Learning objectives
4. Theory
5. Conceptual exercises
6. Python implementation
7. Practical exercises
8. Mini-project
9. Review
