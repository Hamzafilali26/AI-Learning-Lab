# Lesson 1: Data Representation for AI

## Objective

Understand how AI systems represent real-world information using scalars,
vectors, matrices and tensors.

## Concepts Covered

- Scalars
- Vectors
- Matrices
- Tensors
- Dimensions and shapes
- Axes
- Element-wise operations
- Dot products
- Matrix multiplication
- Mean, variance and standard deviation
- Standardization and normalization
- Data leakage

## Why This Matters

Machine learning models operate on numerical structures. Understanding these
structures is required before studying regression, neural networks,
embeddings, recommendation systems or LLMs.

## Lesson Structure

1. Theory and definitions
2. Conceptual exercises
3. NumPy implementation
4. Practical exercises
5. Solutions
6. Small experiments

## Completion Criteria

I should be able to:

- Explain scalars, vectors, matrices and tensors
- Interpret array shapes
- Distinguish element-wise multiplication from dot products
- Explain matrix multiplication
- Use axes correctly
- Standardize a dataset manually
- Calculate Mean Squared Error
